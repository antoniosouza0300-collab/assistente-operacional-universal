# Assistente Operacional Universal

Plataforma modular de inteligência artificial para produtividade, automação, pesquisa, desenvolvimento e criação de conteúdo.

## Objetivos

- Integrar múltiplos frameworks de IA.
- Oferecer processamento local com Ollama.
- Implementar RAG híbrido e memória persistente.
- Orquestrar agentes e fluxos inteligentes.
- Integrar Telegram e APIs externas.
- Manter arquitetura modular, testável e expansível.

## Frameworks

1. LangGraph
2. Ollama
3. LlamaIndex
4. Pydantic AI
5. Haystack
6. CrewAI
7. DSPy
8. Transformers
9. vLLM
10. Fabric
